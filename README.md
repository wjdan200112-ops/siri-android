# سيري AI — مساعد صوتي عربي لأندرويد

تطبيق Android أصلي بلغة Kotlin بواجهة عربية، يدعم التعرف على الكلام وتحويل النص إلى صوت باستخدام خدمات Android المتاحة على الجهاز.

## بناء APK
1. افتح تبويب **Actions** في المستودع.
2. شغّل **Build Siri Android APK** عبر **Run workflow**، أو ادفع تعديلًا إلى الفرع `main`.
3. بعد نجاح البناء، افتح تشغيل الـ workflow ونزّل artifact باسم `siri-debug-apk`.
4. فك الضغط لتحصل على `app-debug.apk`.

## الميزات الحالية
- واجهة عربية RTL.
- الاستماع عبر زر مع التعرف على الكلام باللغة العربية.
- نطق الردود عبر محرك Android Text-to-Speech.
- اختيار الأصوات العربية المثبتة وضبط سرعة الكلام.
- أوامر أولية لفتح Google وYouTube وWhatsApp.

## ملاحظات مهمة
هذه نسخة أولية وليست محادثة ذكاء اصطناعي عامة. تتطلب دقة التعرف على الكلام والأصوات المتاحة خدمات وبيانات اللغة المثبتة على الهاتف. لا يوجد استماع دائم مضمون عند قفل الشاشة أو خروج التطبيق إلى الخلفية. لا تعتبر نسخة APK جاهزة إلا بعد نجاح GitHub Actions وإنتاج ملف البناء.
